# 好好写剧本 Mac App Store 上架执行计划

更新日期：2026-11-15。用途：跟踪提交前的工作和验收证据，不代表已经提交或通过审核。

## 已确认

- 目标平台：Mac App Store；iPhone/iPad 不在本轮范围。
- 首发免费，无应用内购买；AI 为可选功能，用户自行配置第三方模型 API。
- 开发者计划尚未开通；本机代码签名身份检查结果为 0 个有效身份。
- 已安装 GitHub 版为 0.1.58；当前工作目录仍标为 0.1.56，且存在未提交的沙盒修改。技术基线必须先与已发布 0.1.58 核对，不能直接把当前目录打包上传。
- MCP 只保留应用内形态：商店包内提供本地 Streamable HTTP MCP（仅 127.0.0.1，带 bearer token）；需要 stdio 的客户端由站外分发的 shim 满足，不随包提交。沙盒化后的包内 shim 被外部客户端拉起会以 SIGTRAP(133) 终止，结论与限定见 `docs/APP_STORE_MCP_DECISION.md`。CLI 与 shim 同属站外分发渠道：商店包不携带 CLI 二进制、不提供「安装终端命令」入口，也不向 `~/.local/bin` 写链接。

## 阶段 1：账号与基线

用户：注册 Apple Developer Program，完成实名认证、协议及付款。个人账户显示法定姓名作为销售商；如要显示公司名，应先决定组织账户。不要把密码、验证码、私钥发进聊天。

工程：以 GitHub 0.1.58 发布源码为基线，逐项审查并引入沙盒改造，保留现有 GitHub 发行流程；确定商店 Bundle ID 和项目兼容策略后再注册标识，不擅自改变现有标识。商店构建不使用临时签名作为最终签名。

完成标准：账号会员资格生效；可用 Team ID、商店发行证书和配置文件；工程版本来源可复现。账号未开通不阻止阶段 2、3 的准备。

## 阶段 2：商店构建与文件访问（最高优先级）

- 独立商店构建配置：启用 App Sandbox；商店内不提供 GitHub 下载替换应用的更新流程，使用 App Store 更新。
- 审查 security-scoped bookmark 生命周期：授权获取、持久化、失效与重选、移动文件、并发读写、释放。现有代码仅是实现草稿。
- 所有文件入口统一授权：新建/另存为、最近项目、Finder 打开、导入、导出、分集批量导出、自动保存、历史/恢复和备份。
- PDF/OCR 子进程按权限签名，检查真实扫描文件和文本 PDF 的完整导入；不能仅测试弹出选择框。
- CLI：商店版不提供 CLI 安装入口（不写 `~/.local/bin`、不随包携带 CLI）；外部 CLI 与 stdio shim 走站外分发，由用户单独安装。商店内的外部接入只走应用内本地 HTTP MCP。

完成标准：隔离测试目录内新建、保存、退出、重启、最近项目重新打开、编辑再保存全程通过；导入/导出及权限拒绝有明确可恢复结果；不改真实个人剧本作为测试样本。

## 阶段 3：隐私、资料与首发体验

- 检查所有 AI 请求前的明确许可，说明发送哪些内容、发给用户选定的哪个模型服务；涵盖助理、概括、记忆、PDF/OCR 转写与跨集检查。不能仅靠笼统开关假定全部满足审核要求。
- 核查 API Key 存储、诊断日志脱敏、模型服务说明和隐私政策；App Privacy 按实际数据处理填写，不预先承诺“完全不收集”。
- 检查第三方依赖的隐私清单和 Required Reason API；按实际 API/SDK 使用情况填写，不机械复制原因码。
- 服务商网站入口和 API 配置按最新付款/外链规则审查；免费自带 Key 不代表自动免除审核要求。
- 提供公开且可访问的隐私政策、支持网址、中英文介绍、图标、分类、年龄分级、版权及截图；确认服务地区和当地要求。
- 使用原创演示剧本和自有宣传素材，不将个人剧本、密钥或未获许可的影视剧片段上传商店。
- 准备英文审核说明：无应用账号、核心编辑无需模型、如何验证所有可选 AI 功能；不能要求审核员自行付费或跳过 AI 测试。测试凭据须通过受保护的审核资料提供。

完成标准：首次安装、空白页面直接起笔、中文输入法、保存恢复、离线编辑、无模型提示和中英文文案通过；申报与真实网络行为一致。

## 阶段 4：正式构建与上传

正式商店签名、版本/构建号、配置文件、嵌套辅助程序签名及 entitlements 校验；按 Apple 当前支持的上传方式生成提交产物。选择架构前核查现有工具，目前发行验收仅覆盖 Apple Silicon，不能声称支持 Intel。

完成标准：正式包通过本机校验和 App Store Connect 上传处理；处理警告与失败；有干净环境的主要流程验收记录。

## 阶段 5：审核与上线

填写已核对的商店元数据、隐私申报、出口合规和审核备注，提交真实可用构建。建议人工控制正式上线，收到拒审意见逐项处理后再次提交。不承诺固定审核通过日期。
