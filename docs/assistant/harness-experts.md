# 编剧助理：技能体系与专家会审

本文说明 0.1.62 开发分支上的编剧助理（harness）升级：技能与专家如何分工、
每位专家的评审维度与输出结构、多专家会审如何执行与呈现，以及用户如何自定义专家。

## 1. 两层能力：Skill 与 Expert

| | 技能（Skill） | 专家（Expert） |
|---|---|---|
| 面向 | 片段级写作动作 | 场景 / 整稿的判断与改法 |
| 输入 | 当前场景附近正文 + 一句指令 | 场景或整稿 + 项目记忆 + 作者补充要求 |
| 输出 | 改后的片段 | 结构化的评审意见或改写方案 |
| 人格 | 轻，主要是任务模板 | 强，稳定的方法论与判断标准 |
| 调用 | 单次 | 单位专家单次；多专家串行 + 一次汇总 |

两者可以叠加：在对话框里先选专家（决定视角），再选技能（决定动作）。
专家只提供建议，不声称已修改稿件；所有落稿仍走预览 → 确认的既有流程。

## 2. 内置专家

命名全部使用方法论，不使用任何真人姓名。

| 专家 | 评审维度 | 输出结构 |
|---|---|---|
| 节拍表专家 | 开场画面与主题、催化剂与拒绝、中点与伪胜利/伪失败、全盘皆输与灵魂黑夜、终局与终场画面 | 总体判断 / 关键问题 / 修改建议 / 需要作者确认 |
| 三幕结构专家 | 第一幕建置、情节点一、中点转向、情节点二与最低点、第三幕解决 | 同上 |
| 人物弧光专家 | 想要与需要、缺陷与自我欺骗、压力下的选择、关系镜像、转变的可见证据 | 同上 |
| 场景与冲突专家 | 场景目标、障碍与冲突、进入与退出点、信息增量、场景必要性 | 同上 |
| 对白与声口专家 | 人物区分度、潜台词、信息密度、可演性、节奏与停顿 | 同上 |
| 短剧节奏专家 | 前三十秒钩子、冲突升级频率、反转与卡点、集尾悬念、单集信息量 | 同上 |

所有专家共享三条硬规则：

1. 只评审给定文本，引用场景号或原句作为证据，不虚构剧情；
2. 区分事实问题、判断问题、口味问题，口味问题必须标明；
3. 每条建议说明改哪里、怎么改、为什么，不输出空泛评价。

每位专家的完整方法论人格定义在 `crates/screenplay-agent/src/expert.rs`。

## 3. 多专家会审

### 执行方式

- 默认 **串行**：专家 A 完成 → 专家 B → 专家 C，避免并发把费用放大到不可预期；
- 一次最多四位专家，调用次数 = 专家数 + 1（最后一次是汇总）；
- 单个专家失败不影响其他人，失败项单独显示原因；
- 成功专家少于两位时不做汇总，只展示个人意见。

### 范围

- **当前场景**：取当前段落所在场景及后续至多 100 个块，适合快速迭代；
- **整稿**：全文最多 30 000 字；超出时明确提示「请改为按场景分别会审」，避免模型误判篇幅。

### 汇总呈现

汇总由「会审主持」生成，结构固定：

```
## 共识         2–5 条，注明依据来自哪些专家
## 分歧         逐条列出冲突点与各方立场；无分歧时写“无实质分歧”
## 修改优先级   P0 必改 / P1 建议 / P2 可选，每条注明依据专家
## 一句话结论
```

主持被要求：不新增专家没有提出的问题，不替作者裁决审美口味，不抹平分歧。
界面上先按专家逐张卡片展示原文，最后展示「综合意见」卡片，作者可以逐条对照后
自行决定采纳哪些，不自动改稿。

## 4. 自定义专家

目录：`~/Library/Application Support/ScreenplayStudio/experts/<id>/EXPERT.md`

也可以在「设置 → 编剧助理」里管理：导入/导出单个 `EXPERT.md`、改名、打开所在文件夹、
启用或停用专家。启用状态保存在同目录的 `.disabled.json`，不修改 `EXPERT.md` 本身；
停用的专家不会出现在助理面板的会审选择里。会审结束后可在结果上方点「存成我的专家」，
把本次选择的专家方法论合成一位新的自定义专家。

```markdown
---
id: my-expert
name: 我的专家
description: 一句话说明这位专家关心什么
dimensions: 结构，节奏、人物
temperature: 0.5
max_tokens: 2400
---
你只关心一件事：这场戏有没有让主角付出代价。
判断标准：……
输出时引用原句，给出可直接执行的修改方案。
```

规则：

- `id` 必须是安全目录名，且不能与内置专家重名（重名时保留内置）；
- 正文就是人格提示词，建议写清「关注什么、判断标准、反对什么、如何给建议」；
- 改完文件后重启应用生效；解析失败的专家会被跳过，不影响其他专家；
- 自定义专家与内置专家在会审、对话框专家选择中一视同仁。

## 5. 与项目记忆、风格约束的关系

- 会审时把「系统偏好记忆 + 作者确认与锁定笔记 + 自动整理」一并写入提示词；
- 记忆只作为参考资料，不是系统指令；专家不得用记忆替代对正文的证据引用；
- 写作偏好（人称、时态、格式）由项目设置与记忆共同约束，专家建议若违反偏好必须说明原因。

## 6. 已知限制

- 整稿会审受单次上下文上限约束，超长剧本需按场景分批；
- 汇总只做归纳，不做投票式裁决；
- 当前不做流式输出，长稿会审需要等待全部专家完成。
