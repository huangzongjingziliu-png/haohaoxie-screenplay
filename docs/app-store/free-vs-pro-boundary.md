# 免费版与专业版功能边界建议

更新日期：2026-11-16
商业模式：商店版**免费下载 + 非消耗型内购（买断）解锁专业功能**，不做订阅；价格区间建议 68–98 元，最终由用户定；AI 保持用户自带 key；积分制留到后续版本。
标注：**【已核实】**＝代码或现有文档可查；**【判断】**＝我的建议/推理；**【需拍板】**＝需要你决定。

---

## 1. 三条判断原则

1. **免费版必须能独立写完一个剧本**：新建、写作、保存、恢复、导出（至少一种格式）不能上锁。否则评论会直接判死刑，审核也会质疑核心功能是否可用。
2. **付费买的是「交付质量」和「跨设备」，不是「能不能写」**：去水印、专业格式导出、稿号与对比、批量交付、同步。这些是写完之后才需要的，试用期不会卡住创作。
3. **审核员必须在不付费的情况下走完基本验收**：新建 → 输入 → 保存 → 导出 → 重新打开。任何一步要求购买，都是高风险。

**【判断】** 68–98 元这个价位，用户对「专业导出 + 去水印 + 版本交付」的接受度，高于对「AI 额度」的接受度——后者在自带 key 模式下本来就该由服务商收费。

## 3. 水印与限制的具体建议

**【已定】** 水印只加在 PDF 导出上；Word / Markdown / 纯文本 / HTML 均不加水印。水印为「页脚单行」，不含二维码、不遮挡正文：

```
好好写剧本 · 免费版
```

- 位置：每页页脚居中，10pt、50% 灰度。
- 不做页数限制：长片剧本 120 页，限制 10 页等于无法交付，用户会直接卸载而不是购买。
- 不做导出次数限制：无法解释，且容易被绕过。
- 不锁「另存为」和本地文件格式：用户的数据必须随时能完整带走，这是信任底线。

**【需拍板】** 水印文案与是否允许用户手动删除（建议不允许，但不做技术对抗）。

**【已定】** 免费版可导出 PDF（带水印）、Word、Markdown、纯文本、HTML；Fountain 与 FDX 为专业版专属。

## 4. 审核侧注意

**【已核实】** App Store 审核指南 3.1.1 要求数字功能使用 IAP；2.3.1 禁止隐藏功能或与描述不符的卖点。

**【判断】** 具体到本应用：

1. **首屏不弹付费墙**。免费版直接进入写作，专业功能在菜单/导出对话框里以「专业版」标识出现。
2. **审核备注写清验收路径**：新建 → 输入三行对白 → 导出 PDF（免费版带水印）→ 保存 → 重开。并说明专业版解锁内容与恢复购买位置。
3. **所有锁定的按钮都要可点**，点击后展示说明与「恢复购买」，不能是灰掉无反应的死按钮。
4. **1.0 不要出现未实现的功能入口**（例如同步、模板库），否则 2.3.1 风险。
5. **不要在应用内引导去官网/直售版购买**，商店版内不得出现站外购买链接。
