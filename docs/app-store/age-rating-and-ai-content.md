# 年龄分级与「内容生成」声明建议

更新日期：2026-11-16。**分级结论是建议，最终以后台问卷逐项作答的结果为准；涉及责任表述的段落需律师复核。**

## 1. 建议分级：12+

判断依据（按 Apple 问卷的实际问题顺序）：

| 问卷维度 | 本应用情况 | 建议选择 |
| --- | --- | --- |
| 卡通/写实暴力 | 应用自身不提供内容，不展示暴力素材 | 无 |
| 成人/暗示性主题 | 应用不提供；用户自己写的剧本可能涉及 | 无（属于用户内容，非应用提供） |
| 粗俗语言 | 同上 | 无 |
| 恐怖惊悚 | 无 | 无 |
| 医疗/酒精/烟草/毒品 | 无 | 无 |
| 赌博 | 无 | 无 |
| 无限制网页访问 | 无内置浏览器 | 否 |
| 用户生成内容与社交 | 无发布、无分享社区、无关注/私信 | 否 |
| 应用内购买 | 无 | 否 |
| 广告 | 无 | 否 |

为什么不是 4+ / 9+：

- 应用允许导入任意文档、也允许接入第三方模型生成文本，输出内容不由我们控制。用户完全可能写出或生成成人、暴力、粗俗内容。
- 这类"工具本身中性、产出取决于用户"的应用，实践中按 12+ 申报更稳妥，也减少因"AI 输出不当"被质疑分级不实的风险；若完全不接 AI、只做本地编辑，可降到 9+。

为什么不是 17+：

- 应用不提供无限制网页浏览、不提供陌生人社交、不分发内容，不满足 17+ 的典型触发条件。

**如果接入 AI 后出现"应用内可生成并直接展示成人内容"的默认行为，应上调至 17+ 并重新评估。** 当前默认关闭 AI（`cloud_ai_enabled: false`），不构成该情形。

## 2. 「内容生成」相关声明怎么写

应用商店目前没有独立的"AI 生成内容"勾选项，但审核会从三个地方看：年龄分级问卷、审核备注、隐私政策。三处口径必须一致：

### 应用内需要有的说明（建议加在设置 → AI 配置页与首次开启时）

> AI 功能可选，默认关闭。开启后，你在界面上发起请求时，所选内容会发送到你自己填写的第三方模型服务，由该服务生成结果。我们不提供模型、不代付费用、不审查生成内容。生成结果仅供参考，请自行判断后使用。

要点：可选、默认关闭、发给用户自选服务、开发者不审查不担保。

### 审核备注（Review Notes）里要写清

1. 应用无需登录，无测试账号。
2. 核心编辑、导入、导出、版本功能完全离线，可在不配置任何模型的情况下完整体验。
3. AI 为可选功能，需要审核员自备兼容 OpenAI 接口的服务地址与密钥；**不要求审核员付费**，可提供一段预置的本地回环示例（`http://127.0.0.1:<port>`）说明请求格式，或直接说明"跳过 AI 也可完成全部核心流程验收"。
4. 商店版不含 CLI 与自动更新器，相关入口在商店构建中已隐藏。
5. 不收集用户数据，隐私政策链接为 `<待填>`。

### 需要律师复核的表述

- "生成内容仅供参考，不构成专业建议"这类免责句的措辞与效力。
- 若面向中国大陆用户宣传，是否需要在应用内另行展示生成式 AI 相关提示与标识要求。

## 3. 内容合规边界（内部约定，不当成法律结论）

- 不内置任何模型、不预置可用密钥、不代付费用 —— 这条同时是隐私申报成立的前提，别为了体验改成"默认送一些免费额度"。
- 不提供把生成内容一键发布到公开平台的能力。
- 不提供面向未成年人的模式或内容分级开关；如后续增加，年龄分级需重新评估。
