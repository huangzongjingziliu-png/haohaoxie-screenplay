# 好好写剧本使用教程

## 先写起来

欢迎来到好好写剧本。你负责让人物活起来，排版的杂事交给软件。第一次使用，先写一小场戏，再慢慢熟悉其他功能。

普通写作、白板构思、保存和导出都可以先用起来。编剧助理、自动场景概括、自动项目记忆，以及当前的 PDF 和图片导入入口需要先配置模型。

### 新建并选好保存位置

点击“新建”，填剧本名称，按对话框选择保存位置。建议单独建一个剧本文件夹，别让第三稿和最终稿在桌面上打群架。

### 选一种舒服的写法

“标准剧本”适合直接按段落类型写。“自由模式”适合先把想法写出来。“左右分栏”可以同时看文字和排版，两侧会同步定位。

### 试着保存和重新打开

保存后的工程文件以 .screenplay 结尾。退出后可从“最近项目”找回来，也可双击工程文件。

## 写作与格式

在标准剧本中，把光标放进正在写的段落，左侧的段落类型切换器会出现。可以把这一段改成动作、人物、括注、对白等类型。

括注用于“轻声”“停顿”等表演提示，通常放在人物下方；画外音等发声方式可以跟在人物名后。软件会自动显示括号。同一人物在动作之后继续说话时，标准剧本会自动显示 CONT'D，跨页对白也会处理续接。

场景标题可写成“内景 咖啡馆 白天”。标准剧本会按设置统一可识别的标题。地点或时间还没写完整时，先补全，再检查显示效果。

### 用快捷键少挪鼠标

展开段落类型菜单可看到快捷键。Tab 可依次切换常见类型，自定义快捷键在文字与排版设置里调整。

### 调整显示和字体

自由文本底部的滑块可调字号，也能恢复默认。标准剧本的字体、字号和各类段落样式在“设置”的“文字与排版”中调整，可命名保存自己的样式。

### 找一句话

点击“搜索”或按 ⌘F，输入人物名、台词或一个记得住的词，再跳转到结果。专注模式按 Esc 返回。

## 保存、导入与导出

.screenplay 是可以继续编辑的工程，包含剧本和项目资料。PDF、Word 等导出文件用来交稿。交稿前保留一份工程，后面改戏时会省心很多。

保存过的工程默认每 30 秒自动保存，默认每 5 分钟生成一个自动版本。首次写作仍要选好工程保存位置。看底部的保存状态，出现错误时先处理，别只靠感觉判断已经存好。

导入优先选择 FDX 或 Fountain，这些文件直接带有剧本结构。PDF 和图片需要识别文字及版式，扫描模糊、复杂字体、页眉页脚都会增加出错机会。导入后请检查人物、对白、括注和场景。Word 可读取常见的换行、缩进及部分剧本段落样式，普通文章仍需要校对分类。

### 保存与另存为

⌘S 保存当前工程；“更多”中的“另存为”可选新位置。保存出错时会提示，软件不会把失败标成成功。

### 回到之前的版本

撤销和重做适合刚发生的修改。需要回看更早的稿子，在“更多”中打开“版本历史”。

### 退出时选择清楚

有未保存修改时，按对话框选择保存、放弃修改或保留恢复副本。保留恢复副本和保存到正式工程文件是两回事。

### 导出前最后看一眼

点击“导出”，选格式和保存位置。检查分页、名字和台词，尤其是刚从 PDF 或图片导入的内容。

## 白板上搭故事

每张便签对应一个场景。你可以从剧本生成便签，也可以从白板开始构思，先填标题和概括，正文以后再写。

点击“新增便签”会在剧本中加入场景标题。概括留在白板里，不会自动变成一段剧情。拖动便签调整顺序时，剧本和场景栏也跟着调整。

### 直接编辑

双击标题或概括就能输入，点到便签外会提交。标题修改会同步到剧本。长概括可在便签内滚动查看。

### 成组与连线

按住 Command 多选，或在空白处框选便签，再选择成组。选中两个便签可连线；双击连线可写说明，右下角可隐藏连线。

### 调整阅读空间

可改变便签颜色，拖右下角调整宽高。按住鼠标右键再滚动，或用触控板捏合缩放；双指滚动可浏览。箭头按钮跳到该场景，气泡图标写评论。

### 自己写概括也行

概括可以手动填写。配置模型后可开启自动概括，场景内容会发送给当前模型。

## 让编剧助理帮忙

配置好模型后，打开“编剧助理”，选模型和技能，写清你的要求再发送。先拿一小段试试，满意后再扩大范围。AI 也会把台词写得像开会，你有权要求它重写。

修改要求尽量说具体。例如“让这段对白更短，保留两人的冲突，不增加人物，也不要改变结局”。局部修改可从选中的文字、场景或便签右键发送，检查预览后再应用。

### 技能是可重复使用的写法

内置技能可用于润色、扩写、对白优化等。你也可以在设置中添加包含 SKILL.md 的技能文件夹，或点击“创建技能”，让模型起草后自己检查并安装。

### 项目记忆跟着剧本走

配置模型且开启自动整理后，软件会整理项目记忆。它随工程保存，可以在设置里查看。作者笔记用于明确设定，自动整理内容也要定期核对。

### 个性化由你填写

在设置的“个性化”中写你的偏好，例如少用解释性台词。它对这台电脑上的项目生效，不随工程分享，模型不会自动改写。

### 留意内容发往哪里

使用云模型时，相关剧本文字会发给你选择的平台。平台可能收费。密钥保存在这台电脑，分享工程不会把密钥一起带走。

## 模型配置，手把手来

你需要从模型平台取得三样东西。API Key 用来授权调用；Base URL 是平台提供的接口地址；模型 ID 是具体模型的准确名称。三项应来自同一个平台，别把甲家的地址和乙家的密钥凑成一对。

显示名称可以自己取，比如“我的对白助手”。模型 ID 必须照平台写，包括大小写、斜杠和后缀。“DeepSeek”“GPT”这样的简称通常不够。聊天网站的登录密码也不能填进 API Key。

中文版优先介绍国内平台，入口和说明方便中文用户查阅。本机 Ollama 是另一种选择，需要先安装并下载模型。各平台的可用模型、收费和免费额度会变化，请以官方说明为准。

### 第一步，进入配置页

打开“更多”，进入“设置”，选“模型与技能”，点击“管理自定义模型”，再点“添加自定义模型”。

### 第二步，填写模型配置

显示名称随你取。模型类型通常选“兼容 OpenAI 的服务”。模型 ID、服务地址、API Key 从同一家平台复制。OpenAI 类型省略服务地址，本机 Ollama 省略地址和密钥。

### 第三步，检查服务地址

要填文档中的 Base URL，别填聊天网页地址。通常不需要在后面追加 /chat/completions，软件会补上。不要复制示例代码里的引号、空格或换行。

### 第四步，测试连接

点击“测试连接”。收到“API 可用，已收到模型响应”说明这次请求成功。测试只发送一条短消息，不发送剧本；平台仍可能按调用计费。连接成功也不等于模型一定擅长写戏。

### 第五步，保存并允许使用

点击“保存并使用”。云模型还需要勾选“允许云模型处理剧本”。本机 Ollama 无需打开这个开关。

### 第六步，试写一小段

打开编剧助理，确认底部选的是刚保存的模型，发一个简短要求。先看它有没有听懂，再交给它长任务。

### 第七步，保存更多模型

你可以重复添加，用底部的模型选项框切换。密钥在这台电脑输入一次即可记住，编辑时留空会保留旧密钥。换电脑需重新配置，工程文件不会携带密钥。

### DeepSeek

DeepSeek 是国内模型开发者平台，适合直接调用它家的文本模型。注册或登录后，在 API keys 创建密钥，并查看余额与收费说明。软件中选“兼容 OpenAI 的服务”，服务地址填 https://api.deepseek.com/v1，模型 ID 从官方 API 文档复制。

[官方入口](https://platform.deepseek.com) · [官方说明](https://api-docs.deepseek.com/)

### 硅基流动 SiliconFlow

硅基流动是国内的多模型服务平台，适合想在一个账号里试不同文本模型的用户。进入 SiliconCloud 控制台，创建 API 密钥，在模型列表中复制完整模型 ID。软件中选“兼容 OpenAI 的服务”，中国站服务地址填 https://api.siliconflow.cn/v1。先看价格，再试一小段。

[官方入口](https://cloud.siliconflow.cn) · [官方说明](https://docs.siliconflow.cn/docs/userguide/quickstart)

### 本机 Ollama

想用本机模型，可先安装并打开 Ollama，按其官方说明下载一个本地文本对话模型。软件中选择“本机 Ollama”，填本机已有的完整模型名，包括标签；无需填 API Key。请选已经下载到本机的模型，别误选需要云服务的模型。性能取决于电脑和模型大小。

[官方入口](https://ollama.com/download) · [官方说明](https://docs.ollama.com/api/openai-compatibility)

## 遇到问题怎么办

### 401 或密钥无效

重新从平台复制 API Key，检查是否多了空格、是否已被撤销、是否填错了平台。不要把完整密钥发给别人。

### 404 或模型不存在

核对服务地址和完整模型 ID，确认账号有权使用该模型。模型显示名称和调用 ID 可能不同。

### 429、余额不足或额度用完

检查平台余额和调用限制。按提示等待，或切换另一个已经配置好的模型。换模型后先测试连接。

### 连接超时

检查网络、服务地址和平台状态。本机 Ollama 需保持运行，并已经下载对应模型。测试通过后，再试短任务。

### 提示需要配置模型

检查是否保存并选中了模型，云模型开关是否开启。点击提示框中的配置入口即可直接进入。

### 导入格式仍有问题

优先尝试同一原稿的 FDX 或 Fountain。保留原文件，记录哪页、哪个人物或段落错了，再联系我们。模型和 OCR 都需要具体的错误样本，光说“它又写歪了”不太好抓现行。

### 我只是想写剧本，不想用 AI

可以。普通写作、白板手动概括、保存和导出不依赖模型。先把故事写出来，模型配置可以以后再说。

## 连接外部 Agent

CLI 和 MCP 是让其他 Agent 操作好好写剧本的入口。Codex、WorkBuddy、TRAE 等客户端能否接入，取决于它们是否支持本机命令或本地 MCP。

打开“更多”里的“连接外部 Agent”，按界面的步骤检查工具路径并复制配置。MCP 配置要填进客户端的 MCP 设置，单独粘贴到聊天框不会启用服务。当前内置服务用于同一台 Mac 的本地连接。

接好之后，先要求 Agent 只读查看当前工程，核对名称和路径，再让它修改。软件内置的编剧助理有自己的模型配置，外部客户端也有自己的配置，两边的账号和密钥不会自动通用。
