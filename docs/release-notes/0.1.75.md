# 0.1.75 更新说明

这一版包含两轮改动：先把审阅发现的数据安全问题补齐，再做一轮界面精简。合并发布，建议所有用户升级。

## 数据安全（0.1.74）

### 工程锁

- 同一工程的写锁改为操作系统文件锁（`flock` 独占、非阻塞）。旧实现「先建锁文件、再写 PID」存在窗口会被另一实例当成陈旧锁删掉，两个实例可能同时写同一工程；新实现由内核保证原子性。
- 释放时校验归属，只清理本实例的标记；进程崩溃时锁随文件描述符自动释放。
- 残留的旧锁文件内容不再把空闲工程误判为「正在使用」。

### 崩溃恢复

- 恢复稿默认落成**未绑定**的新副本，不再直接绑回原文件，避免用旧恢复稿覆盖更新的正式稿；确认内容后另存为即可。
- 「保留恢复副本并关闭」改为独立副本；正常退出不会删掉它，后续打开别的工程也不会覆盖。
- 恢复点写入失败会明确报错并可重试；关闭流程失败会中止关闭并提示。

### 保存与退出

- 退出请求一开始就建立后端保存屏障：确认期间自动保存不会落盘，「不保存」的边界成立。取消退出会解除屏障。
- 保存目标路径移入保存锁内解析；自动版本创建失败不再连累正文保存。

### 编辑安全

- revision 冲突后自动重新取基准并重试一次，草稿不再卡在旧 revision。
- 剪切改为单事务：先固定选区与 revision，剪贴板写入成功后才按同一集合删除。
- 多行粘贴改为一次 `apply_block_batch` 提交，失败整体撤销，不丢原段尾。
- 白板分区名称/说明纳入待提交草稿：Esc 关板或退出前先提交，失败保留草稿。
- 外部工具写入后，前端先 flush 本地草稿再拉权威状态。
- 技能改名改为临时文件 + rename 原子替换。

## 界面

### 保存状态三态

状态栏不再只有「已保存 / 未保存」，而是区分：

- **输入未提交**：文字还在编辑器里，尚未提交到文档（会自动提交）；
- **等待写盘**：已提交到文档，还没写入磁盘；
- **已写盘**：所有修改都已落盘。

保存失败时仍优先显示错误并提供重试提示。

### 白板工具栏分组

顶部按「创建 / 组织 / 视图」分组：

- 创建：新增便签、新增分区、构思模板、套用模板；
- 组织：撤销/重做、自动概括、模型自动划分、配置模型；
- 视图：便签外观、缩放与重置。

对象级操作（连线、选中便签配色、恢复正方形）只在选中便签后出现，未选中时不再展示一排灰按钮。

### 编剧助理

关闭编剧助理面板不再销毁对话与会审结果；再次打开可继续之前的会话。

### 工具栏

「历史记录」只保留工具栏图标一个入口（⌘Y 不变），「更多」菜单中的重复入口已移除。

## 兼容

- 不改变工程数据格式，已有工程照常打开。
- 旧版本留下的恢复记录仍可读取；恢复后请另存为新副本。
- 版本号：0.1.75（商店渠道仍为 1.0.0，独立配置）。
