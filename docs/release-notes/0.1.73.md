# 0.1.73 更新说明

这一版收拾界面细节：元素菜单看得到当前类型、能钉住，工具栏收成图标，PDF 封面文字回正。

## 元素菜单

- 折叠后的胶囊不再只写「元素」，直接显示光标所在块的类型（对白、动作、场景标题……），并随光标实时更新。
- 吸附在左侧时，标题同样显示当前类型，不再是一句笼统的「元素」。
- 折叠态在胶囊左侧新增图钉按钮，落在纸面左侧的空白 gutter 里，不遮正文：
  - 点一下钉住，菜单固定在当前落点，移动光标、滚动页面都不再跟着跑；图钉填充高亮，一眼能看出已钉住。
  - 再点一下恢复跟随光标。
  - 钉住状态会记住，重启后保持；重启后聚焦到具体块时才落位，不会先悬在角落。
- 菜单和按钮按实际宽度定位，优先放在正文列左侧；空间不足时自动翻到右侧或贴边停靠，避免压住正文。

## 工具栏

- 搜索改为放大镜图标。
- 历史记录、新建、导入、保存、更多、场景白板、连接外部 Agent、编剧助理一并收成图标，减少一排文字。
- 所有图标按钮保留悬停提示（tooltip）和 `aria-label`，仍是原生按钮，Tab / 回车键盘可达。
- 视图模式与导出格式仍用原生下拉，保持可读性。

## PDF 封面

- 标题页文字改为水平居中：标题、署名等封面行统一按页宽中点排版，不再偏左。
- DOCX 导出本身不生成标题页，因此没有同类偏移；本版未新增封面页。

## 兼容

- 不改变工程数据格式，已有工程照常打开。
- 元素菜单的展开/收起、吸附位置、图钉状态会保存在本机偏好里。
- 版本号：0.1.73（商店渠道仍为 1.0.0，独立配置）。
