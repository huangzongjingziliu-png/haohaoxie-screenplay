# 0.1.70 更新说明

这一版集中修整跨块多选的边界行为：选中块后误删、剪切丢内容、粘贴串台、撤销后按键被吞，以及合并对白行、浮动菜单和无障碍细节。

## 选中块后，焦点离开正文就不再误删

- 以前选中若干段后去点工具栏、场景板、元素弹层或帮助面板，块选区仍留在后台，此时按 Delete/Backspace 会把正文里的段落删掉。
- 现在焦点只要离开正文（进入任何非正文控件），块选区立即清除；退格、Delete、⌘C/⌘X、Esc、粘贴共用同一套「焦点是否在正文」判断。
- 选中块后点工具栏按钮、打开场景板再按 Delete，不会再误删背后的正文。

## 剪切改为事务，复制失败不删正文

- ⌘X 的顺序固定为：先落盘正在输入的草稿 → 取稳定内容 → 写入系统剪贴板并确认成功 → 才删除。
- 系统剪贴板不可用或被拒绝时，正文保持原样，并提示「复制到剪贴板失败，所选段落未删除」。
- 键盘 ⌘X、macOS 原生「编辑」菜单的剪切、括注选中后的剪切三条路径行为一致；剪切到其他应用不会再丢内容。

## 粘贴只在正文里生效

- 只有焦点位于剧本正文时才按块粘贴；在搜索框、标题框等输入框里粘贴，不会再往剧本里插入内容。

## 多选操作与显示

- 撤销或文档变化后，已不存在的选区端点会自动清理；不会再出现「看不到高亮、但 Delete 被吞掉」。
- 拖选时把鼠标拖回起点会收缩回单块，不再固定停在最远范围。
- 点击左侧选中条后会立刻把键盘焦点交回正文，⌘C/⌘X 与 Shift+↑/↓ 可以马上使用。
- 没有块选区时，Shift+↑/↓ 会从当前块开始按块选择（文字选区未折叠时保持原生扩选）。
- 合并对白行：左侧选中条选中整组并显示选中态，沿选中条拖过该行会继续扩展范围；按 Esc 后 Shift 点行内文字可单独选中其中的块。
- 选中态仍是浅蓝底 + 左侧蓝竖线；Esc 清除。块选区变化会通过读屏播报「已选中 N 个段落」。
- 容器标记为可多选列表、选中项带 `aria-selected`；左侧选中条不再对辅助技术隐藏，可用读屏激活。

## 其他

- 同一源块被分页拆成多段时，跨页选中按源文本偏移在单块内删除，不再出现选得中却删不掉。
- 浮动元素菜单靠近窗口底部时会向上翻转；高度超过可用空间时限高滚动，不再被裁掉。
- 元素菜单用键盘选完类型后，焦点会回到正文对应段落，可以继续输入。
- 删除场景标题后，场景板里对应的卡片与分组中的场景引用会一并清理，不再残留无法对应正文的「幽灵场景」；撤销时随正文一起恢复。

## 兼容与说明

- 不改变已有工程的数据格式，打开旧工程不受影响。
- 版本号：0.1.70（商店渠道仍为 1.0.0，独立配置）。
