# 0.1.66 更新说明

这一版改了三处常用界面的手感：助理面板能明显拖宽，滚动正文时左侧场景会跟着走，元素类型菜单可以钉住不动。

## 编剧助理面板

- **拖动条更明显**：面板左缘的拖拽热区加宽，常态显示一条细线，鼠标移上去变蓝并出现握把，光标为左右箭头。
- 宽度范围仍是 300–480px，默认 340px，拖动后的宽度会记住。

## 场景列表跟随

- **滚动即跟随**：用滚轮或触控板上下浏览正文时，左侧场景列表自动高亮当前所在场景，不需要先在正文里点一下。
- **只改高亮，不抢滚动**：跟随只更新高亮，不会反过来改变编辑区的滚动位置。
- **手动跳转有保护**：点左侧场景、搜索结果、白板或跨集证据跳转后，约 0.9 秒内不会被滚动跟随改回目标场景。
- 编辑正文时暂停跟随，避免正在输入时光标所在段落被别的段落顶掉高亮。

## 元素类型菜单

- **可吸附固定**：元素类型菜单（场景标题 / 动作 / 人物 / 括注 / 对白 / 转场 / 镜头 / 注释 / 章节 / 概要 / 普通文本）可一键吸附到**顶部横排**或**左侧竖排**，钉住后位置固定，不再跟着光标移动。
- **默认吸附在左侧**：首次使用即固定在编辑区左侧竖排；想恢复原来的跟随光标模式，点菜单末尾的「跟随光标」即可。
- 吸附位置会记住，重启后保持。

## 兼容与说明

- 只调整界面，不改剧本数据与导出结果。
- 版本号：0.1.66（商店渠道仍为 1.0.0，独立配置）。
