# 0.1.72 更新说明

这一版补上退出保护：稿子有未保存修改时，⌘Q、关闭窗口、Dock 退出都会先问一句，不再直接关掉、指望恢复点兜底。

## 退出前先确认

- 有未保存修改时，按 ⌘Q（或关闭窗口、从 Dock 退出应用）会弹出确认：**保存并退出 / 不保存 / 取消**。
- 「保存并退出」会先落盘再退出；保存失败或没有真正写进文件时**中止退出**，留在当前窗口并给出提示，不会带着未保存内容消失。
- 「不保存」放弃本次修改后退出；「取消」回到编辑，内容和光标都还在。
- 没有未保存修改时保持原样：直接退出，不再多弹一个窗。

## 关窗与退出共用同一套判断

- 标题栏关闭按钮、⌘W、⌘Q、Dock 菜单「退出」、系统注销都走同一套「先 flush 草稿 → 再判断是否 dirty」的流程。
- 判断前会先把编辑器里还在防抖队列中的文字提交给后端，刚敲下的字也算「未保存」，不会漏掉。

## 多窗口各判各的

- 每个窗口按自己的稿子判断是否需要确认；退出其中一个窗口不会牵连另一个窗口里的未保存内容。
- 已经处于退出确认中时再次触发退出，不会叠加弹窗。

## 兼容与说明

- 不改变工程数据格式，已有工程照常打开。
- 退出确认沿用现有的项目管理语义：「不保存」清除本次会话的恢复副本；已经保存到文件的内容不受影响。
- 版本号：0.1.72（商店渠道仍为 1.0.0，独立配置）。
