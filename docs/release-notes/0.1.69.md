# 0.1.69 更新说明

这一版修了两处正文编辑的老问题——括注选中后删不掉、不能跨块选择复制粘贴，并整理了元素菜单的跟随与折叠。

## 括注选中后可以正常删除

- 括注两侧的圆括号是装饰元素，不在正文可编辑区里。之前把「（低声）」连括号一起选中再按退格或删除，浏览器无法跨过这层边界，文字删不掉。
- 现在整段选中、只选中半段、括号里再套括号、选中后 ⌘X 剪切，都能正常处理；选区跨到相邻块边界时会把首块前缀与末块后缀合并，不会把整段误并进上一块。
- 没有选区时，在段首按退格的合并行为保持不变。

## 跨块多选与复制、剪切、粘贴

- **怎么选**：每段左侧留了一条很窄的选中条（悬停时出现浅灰竖线），单击选中整段，Shift 单击另一段的选中条扩展范围，按住拖过连续段可以连选；选中一段后也可以按 Shift+↑/↓ 按块扩展。还支持按住 Shift 点击正文段落、拖过块边界，或按 ⌘A 选中当前场，再按一次 ⌘A 选中全文。三击括注整行会整块选中，退格/删除时连同两侧括号一起去掉。
- **选中态**：被选中的块整行显示更明显的浅蓝底色和左侧蓝色竖线，与当前编辑块的浅黄底色区分；按 Esc 立即取消选中。
- **⌘C / ⌘X / ⌘V**：复制、剪切、粘贴按块搬运，保留每块的元素类型（场景标题、动作、人物、括注、对白、转场等）与先后顺序；跨场选择、粘贴到文末、粘贴到空工程都能用。⌘X 已兼容 macOS 原生「编辑」菜单对快捷键的截获，不会再出现按了没反应。
- **剪切与粘贴可撤销**：剪切、批量删除、整块粘贴各算一个撤销单元，按一次 ⌘Z 即可整体恢复；粘贴到某段中间时插在该段之后，不会把原文字拆断。
- 中文输入法组字期间不会拦截这些组合键。
- 复制时系统剪贴板里同时写入纯文本；粘贴到其他应用得到的是普通文字，不会带格式标记。

## 元素菜单：跟随光标与折叠

- **点「跟随光标」当场生效**：修复了之前只写偏好、菜单没真正切回浮动形态的问题。点一下立即切到浮动菜单，并锚定当前段落或最近编辑的段落；没有活动段落时锚定第一段并滚动到可见处。
- **可折叠**：菜单顶部新增「元素」标题栏，右侧箭头可收起；收起后只留一条窄条（跟随光标模式是一枚「元素 ▸」小胶囊，左侧吸附模式是一条竖直窄条），尽量不挡正文。
- **选完自动收回**：展开状态铺出十一项元素与快捷键提示，点任意一项后菜单自动收起。
- **记住折叠状态**：收起/展开会保存在本地，下次打开沿用；跟随光标与贴左侧两种锚点下收起态都保持在原位，不会跑到屏幕角落。
