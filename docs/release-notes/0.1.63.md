# 0.1.63 更新说明

0.1.62 之后的一组缺陷修复，重点是白板分区与编剧助理会审的数据一致性。

## 白板

- **从组中间拖走便签不再丢成员**：以前组 `[a,b,c]` 拖走 `b` 后剩下的 `c` 会被静默踢出分组；现在会把断开的成员拆成独立的分组，一张都不会丢。
- **剩余不足两张自动解散分组**：避免出现只有一张便签的「组」。
- **自动划分按组归区**：同一场景组的成员会统一落到票数最多的分区，不会出现组显示在首成员分区、成员数据却散在别处。
- **覆盖前先确认**：已经手动分过区时，再点「用模型自动划分」会先确认；提示里的场景数只统计真正写入的有效归属。
- **分区名称与说明改为失焦提交**：输入过程中不再逐字写盘、逐字产生历史记录，撤销粒度更合理。

## 编剧助理

- **专家 `max_tokens` 真正生效**：自定义专家在 `EXPERT.md` 里写的上限会带进请求，不再固定 4096。
- **未汇总时说清原因**：选中多位专家但只有一位成功时，界面会提示「至少需要 2 位才能比较汇总」，不再留白。
- **错误信息可读**：模型调用失败统一收敛为超时、鉴权失败、地址或模型不可用等提示，不再把端点、模型名等内部信息暴露在面板里。
- **自定义专家加载问题可见**：`EXPERT.md` 解析失败或 id 与内置专家冲突时，面板会列出具体文件和原因，不再静默跳过。
