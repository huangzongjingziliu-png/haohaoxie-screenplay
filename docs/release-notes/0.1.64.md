# 0.1.64 更新说明

一次界面整理：工具栏重新分组，右侧编剧助理面板可以拖动调宽。

## 工具栏

- **按「文件 / 视图 / 协作」三组排列**，组间加分隔线，常用操作更好找。
- **缩放收进二级菜单**：原来的「缩放 −/+」合并为一个「缩放 xx% ▾」按钮，展开后可选择适应纸宽、缩小、放大，快捷键行为不变。
- **功能一个都没少**：新建、导入、保存、导出、历史记录、视图模式、左右互换、白板、搜索、连接 Agent、编剧助理、设置等仍全部保留；「更多」菜单里的另存为、版本历史、检查更新、帮助入口不变。

## 编剧助理

- **面板可拖宽**：拖动面板左边缘可在 300–480px 之间调整，默认 340px。
- **记住上次宽度**：关闭并重启应用后保持上次拖动的宽度。

## 兼容与说明

- 版本号：0.1.64（商店渠道仍为 1.0.0，独立配置）。
- 数据格式、快捷键与已有工程均无变化。
