# 0.1.62 更新说明

## 新增：白板构思分区

场景白板现在可以像真实白板那样，先划线分区，再往区里贴便签。打开「白板」，用「构思模板」下拉套用现成的分区方案：

- **三幕电影节拍表**：第一幕 · 建置 / 第二幕 · 对抗 / 第三幕 · 解决，每区带节拍提示。
- **短剧分集骨架**：第 1 / 2 / 3 集，每区提示「开场钩子 → 冲突升级 → 反转 → 结尾钩子」。
- **空白标准剧本**：清空分区，回到自由白板。

用法与纸上构思一致：

- 便签拖进某个分区就自动归属该区，拖回「未分区」即取消归属。
- 分区可以改名、改颜色、收起/展开，也可以整体拖动排序。
- 删除分区不会删戏：区里的便签自动回落到「未分区」，并有提示说明。
- 归属、分区顺序、收起状态都随工程保存，切到别的工程再回来仍在。

分区只是构思工具，不影响正文；手动套模板、贴便签都不需要模型。只有「让模型读整稿自动划分」需要先在设置里配置模型，未配置时该入口为灰。

## 新增：编剧助理专家会审

「编剧助理」从单一聊天升级为带方法论的会审工作台：

- **按钮开关**：点「编剧助理」打开右侧面板，再点一次关闭，右上角叉号保留。
- **六位方法论专家**：节拍表、三幕结构、人物弧光、场景与冲突、对白与声口、短剧节奏。每位专家有自己的评审维度、固定输出结构和证据规则（必须引用场景号或原句，区分事实、判断与口味）。
- **多专家会审**：可同时选 1–4 位，依次执行后由「会审主持」汇总成共识、分歧与 P0/P1/P2 修改优先级，不会把分歧抹平。
- **范围与方式**：可审当前场景或整稿（单次上限 3 万字，超出会提示分批）；方式是「评审」或「改写建议」。
- **专家人格对话**：输入框上方可把日常对话切换成某位专家，仍按该专家的判断标准回应。
- **自定义专家**：把自己的方法写成 `EXPERT.md` 放进用户目录的 `experts/<id>/`，重启后出现在列表里，内置专家不可被覆盖。

## 调整：新建剧本不再选模板

新建对话框去掉了模板单选框，只保留剧本名称与两条说明。构思模板移到白板里使用，与「先有构思、再动笔」的顺序一致，也避免新建时误选模板把正文写歪。

## 修复

- 新建对话框提示文字与输入框挤在一起、两段之间没有间距，改为分组排版，深色下同步配色。
- 移除随模板单选框一起废弃的样式规则。
