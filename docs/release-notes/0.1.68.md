# 0.1.68 更新说明

这一版主要是界面整理：主编辑界面的工具栏、栏头、状态栏统一了层级和对齐，元素菜单默认改成跟随光标，并把快捷键直接标在菜单里。

## 主编辑界面更整齐

- **工具栏标题上移**：剧本标题、稿号和未保存提示移到工具栏最左侧，和折叠导航按钮同排，不再单独占一块底部空间。
- **按钮分组更清楚**：工具栏按钮改为分段控件样式，去掉重复边框和组间分隔线，选中态更明确。
- **三条栏头对齐**：左侧导航 tabs、左面板标题、右侧面板标题统一为同一高度，横向基线齐平。
- **拖拽落点不再混淆**：拖动场景时的落点提示改为紫色，与当前场景的蓝色高亮区分开。
- **底部状态栏统一**：高度和间距统一，路径列固定比例，长路径不再把其他信息挤乱。

## 元素菜单

- **默认跟随光标**：新用户首次使用时，元素菜单浮在光标所在段落旁。之前手动选过「吸附顶部 / 吸附左侧」的用户保留原选择。
- **菜单内显示快捷键**：场景标题、动作、人物、括注、对白、转场、镜头、注释、章节、概要、普通文本后面都标出对应组合键，例如 ⌘1、⌘2、⌘0、⌘⌥1。
- 中文输入法激活时组合键照常可用，不会和候选词数字键冲突；也不占用 ⌘Z、⌘S、⌘F 等已有快捷键。

## 兼容与说明

- 不改变已有工程的数据格式，打开旧工程不受影响。
- 已保存的元素菜单位置偏好不会被覆盖。
- 版本号：0.1.68（商店渠道仍为 1.0.0，独立配置）。
