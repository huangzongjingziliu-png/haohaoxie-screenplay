# 0.1.61 更新说明

## 新增：深色模式

设置里多了「外观」，可选 **浅色 / 深色 / 跟随系统**，改完立即生效。

- 「跟随系统」会跟着 macOS 的外观切换，不用手动改。
- 深色下按钮、工具栏、对话框统一改为深底浅字，修掉了之前局部暗色块和白底白字的问题；禁用态也保证文字可辨认。
- **导出不受影响**：PDF、Word、HTML 和纸面预览始终使用浅色纸面，深色只是界面外观。
- 没设置过的用户升级后仍是原来的浅色，不会被强制换掉。

## 新增：新建工程模板

「新建剧本」现在可以先选模板，内置三套：

- **空白标准剧本**：不预置内容，从第一场开始写。
- **短剧分集骨架**：按集生成竖屏短剧结构，每集预置开场钩子、冲突升级、反转与结尾钩。
- **三幕电影节拍表**：按三幕与经典节拍预置场景骨架，适合长片、网剧的整体规划。

模板只是预置骨架，建好之后就是普通工程，可以随意增删场次。想加自己的模板，把 JSON 文件放进界面提示的模板目录即可，重启后在列表里选。

## 商店版免费/专业版边界

商店版（App Store 渠道）采用免费下载、一次买断解锁专业版，不做订阅；直售版和命令行版行为不变，不加载付费墙。

免费版就能完整写作、保存，并导出 **PDF / Word / Markdown / 纯文本 / HTML**。

专业版一次性买断，解锁桌面交付相关的这几项：

- PDF 导出不带页脚水印（免费版每页底部有一行「好好写剧本 · 免费版」）
- Fountain / Final Draft（FDX）导出
- 分集批量导出，以及分集合并为单个 PDF
- 命名稿号与版本对比导出
- 导出文件名与封面携带稿号

已购状态由 App Store 交易记录决定，换机后用弹窗里的「恢复购买」即可恢复；退款撤销只影响导出选项，不会锁住你的项目文件。
