# 0.1.65 更新说明

设置里新增「编剧助理」页，把专家从"写在文件夹里"变成可管理的专家库。

## 专家库

- **一处管理**：设置 → 编剧助理 列出内置专家与自定义专家，支持启用/停用、改名、打开所在文件夹。
- **导入导出**：单个专家以 `EXPERT.md` 保存，导入导出沿用同一格式；导入后立即出现在助理面板里，不需要重启。
- **两种类型**：
  - **审稿型**：参加「专家会审」，对结构、人物、场景、对白等给出判断与修改建议；
  - **写作型**：出现在助理对话的写作专家列表中，做单步写作、续写或改写。
  - 内置 6 位专家均为审稿型；自定义专家在 `EXPERT.md` 里用 `kind` 指定类型，不写时默认审稿型。
- **存成我的专家**：会审结束后，可在结果上方把本次选择的专家方法论合成一位新的自定义专家，并选择审稿型或写作型。

## 界面

- 助理面板的会审选择只列审稿型专家，对话的写作专家列表只列写作型专家，避免选错场景。
- 设置页与助理面板均适配浅色、深色两套外观。

## 兼容与说明

- 既有自定义专家目录与 `EXPERT.md` 照旧可用，未写 `kind` 的文件按审稿型载入。
- 版本号：0.1.65（商店渠道仍为 1.0.0，独立配置）。
