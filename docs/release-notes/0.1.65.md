# 0.1.65 更新说明

「模型与技能」页新增技能库：技能集中在设置里管理，在助理面板里使用。对外只有「技能」一个概念，不再区分另一套叫法。

## 技能库

- **一处管理**：「设置 → 模型与技能」列出内置技能与自定义技能，支持启用/停用、改名、打开所在文件夹。
- **导入导出**：自定义技能以单个 `SKILL.md` 保存，导入导出沿用同一格式；导入后立即出现在助理面板里，不需要重启。
- **两种类型**：
  - **审稿型**：参加「会审」，对结构、人物、场景、对白等给出判断与修改建议；
  - **写作型**：出现在助理对话的写作技能列表中，做单步写作、续写或改写。
- **内置审稿技能带方法论来源**：布莱克·斯奈德的节拍表、悉德·菲尔德的三幕结构、约翰·特鲁比的人物弧光、罗伯特·麦基的场景与冲突、罗伯特·麦基的对白与声口、竖屏短剧流派 · 短剧节奏。
- **内置写作技能**：续写、润色、扩写、对白优化。
- **存成我的技能**：会审结束后，可在结果上方把本次选择的技能方法合成一个新的自定义技能，并选择审稿型或写作型。

## 界面

- 技能并入「模型与技能」页，模型接入部分保持不变。
- 助理面板的会审选择只列审稿型技能，对话的写作技能列表只列写作型技能，避免选错场景。
- 设置页与助理面板均适配浅色、深色两套外观。

## 兼容与说明

- 新技能统一保存在 `ScreenplayStudio/skills/<id>/SKILL.md`；旧目录 `experts/<id>/EXPERT.md` 继续读取，未写 `kind` 的旧文件按审稿型载入。
- 版本号：0.1.65（商店渠道仍为 1.0.0，独立配置）。
