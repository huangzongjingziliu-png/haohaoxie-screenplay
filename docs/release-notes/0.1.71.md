# 0.1.71 更新说明

这一版加入多实例：可以同时打开多份稿子，各自一个窗口，互不干扰。之前双击另一份工程会把当前窗口里的稿子替换掉，现在会另起一个窗口。

## 同时打开多份稿子

- 已开着一份稿时，再双击另一份 `.screenplay` 工程，会在**新窗口**里打开它；原窗口的内容、撤销历史和光标位置都不变。
- 工具栏「更多 ▾」新增「在新窗口中打开…」，可以手动挑一份稿子在独立窗口里打开。
- 关掉其中一个窗口，其他窗口照常使用；保存、撤销、导出都只作用于自己那一份。

## 重复打开有明确提示

- 同一份工程已经在当前窗口时，会提示「这个工程已经在当前窗口中打开」，不会重复加载。
- 同一份工程已在另一个窗口打开时，会把那个窗口切到前台并提示，不会出现两个窗口同时写同一个工程。
- 工程文件锁会记录持有它的实例，只有该实例退出后其他窗口才能接手。

## 最近列表与恢复

- 最近打开列表由多个窗口共用一份，加入跨进程写锁与原子写入，两个窗口同时更新不会互相覆盖，两条记录都在。
- 每个窗口有独立的桥接描述文件（CLI/MCP 侧），窗口获得焦点时「活动实例」指针跟随当前窗口。
- 崩溃恢复记录会带进程标记：另一个窗口仍在运行时的草稿不会被误判成崩溃残留，也不会被别的实例消费掉。

## 兼容与说明

- 不改变工程数据格式，已有工程照常打开。
- 新增菜单项仅在 macOS 生效；未打包运行（开发模式）时无法拉起新实例，会给出提示。
- 跨实例复制粘贴走系统剪贴板，与单实例时的块复制/剪切行为一致。
- 版本号：0.1.71（商店渠道仍为 1.0.0，独立配置）。
