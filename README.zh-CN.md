# 好好写剧本

面向 Mac 的本地剧本编辑器。支持中英文界面、标准剧本和自由文本、场景白板，以及可选的编剧助理。

**公开测试版 0.1.25。** 安装包见 [Releases](https://github.com/huangzongjingziliu-png/haohaoxie-screenplay/releases)。 已验收的平台为 Apple 芯片 Mac；不是 App Store 版本。

## 为什么用好好写剧本？

**先把故事写出来，再把它整理成剧本。你可以自己写，也可以让 AI 帮着改。**

### 三个核心特点

1. **让你惯用的 AI 助手直接操作剧本。** 内置 CLI 和 MCP，可供具备本机工具能力的 Codex、WorkBuddy、TRAE 等 Agent 客户端接入。接通后，你可以让它读取场景、修改对白或调整剧本，不必反复在聊天框和编辑器之间复制粘贴。需要先配置连接；把配置文字粘进聊天框，并不等于已经接通。
2. **按自己的习惯写，同时看见剧本排版。** 可以在自由模式中输入文字，旁边同步显示标准剧本视图；也可以只打开其中一种模式。还不熟悉剧本格式，或者想先专心写故事时，可以从自由模式开始，再检查人物、动作、对白等分类和排版。格式识别有歧义时仍需要校正，软件不会把任意散文自动变成完整剧本。
3. **编辑器里就有编剧助理，模型由你选择。** 不用离开当前项目，就能讨论情节、润色对白、扩写场景或处理选中的内容。可保存和切换自定义模型，搭配写作技能使用；项目记忆记录工作情况，系统记忆记录你明确告诉助理的偏好，均可在设置中查看和编辑。局部修改可以先预览，再决定是否应用。AI 是可选功能，核心编辑无需配置模型；使用云模型时，相关内容会发送到你配置的服务。

### 另外三点实用之处

- **把场景铺开，方便看故事结构。** 每个场景是一张便签。白板、场景列表和正文使用同一套场景顺序，拖动排序会同步到剧本；还可成组、评论、连线，把修改想法放在对应场景旁。白板按剧本顺序组织，不是任意摆放的自由画布。配置模型后，可选择生成场景概括。
- **文件在自己手里，修改有回退余地。** 剧本保存为本机 `.screenplay` 工程，支持版本历史、恢复和多格式导出。无需使用 AI 也能写作；选中一部分交给助理修改时，可以先检查结果再应用。记忆目前保存在本机，不会自动随工程迁移到其他电脑。
- **排版可以适应你的写作习惯。** 除默认格式外，可按动作、人物、对白等段落类型调整字体、字号、粗细和颜色，命名保存自己的样式方案。界面字号与纸面字号分开设置，缩小纸面时，操作标签仍能看清。

### 与其他剧本软件有什么区别？

场景白板、版本历史和格式设置，本身并不是本软件独有的功能。好好写剧本更值得关注的是这三种工作方式放在一起：**自由文本与剧本排版同步、外部 Agent 可通过工具接入、内置助理围绕当前项目工作。** 你可以先写故事、再检查格式，也可以在同一个项目中让 AI 协助修改，而不必只依赖手工编辑。

当前是公开测试版，不代表已经达到成熟专业剧本软件的全部功能和稳定性。PDF／图片转写、格式识别和 AI 建议都应由作者检查。

## 安装与使用

GitHub Release 提供 DMG 安装包。打开后拖入“应用程序”即可安装，无需安装 Rust、Node.js 或 Codex CLI。源码 ZIP 不是安装包。发布说明会如实标注签名和公证情况；不要关闭系统安全保护。

语言选项位于“更多 → 设置 → 通用 → 界面语言”：跟随系统、简体中文、English。只切换软件界面，不翻译剧本正文，也不改变剧本排版。部分后端诊断和内置技能说明在测试版中仍为中文。

主要功能包括剧本排版、自定义段落样式、场景拖动排序、白板、版本历史、恢复和多格式导出。项目格式为 `.screenplay`。

PDF／图片转写和 AI 功能仍属实验功能，使用后需要校对。没有模型也可使用核心编辑功能。模型需要自行配置，不提供共享密钥，不承诺无限免费额度。
