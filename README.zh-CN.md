# 好好写剧本

**AI 时代的专业剧本工作台。**

写一场戏，先要管人物站哪儿、对白缩进多少。改一场戏，又得把正文复制进 AI 聊天框，再把结果搬回来。写到几十场，还要来回翻页，找那场本该提前出现的戏。

好好写剧本把这些事放在同一个工程里。你可以先自由写，随时看标准排版；把场景铺成便签，拖动就能调整正文顺序；需要改稿时，让助理在项目里帮忙，检查结果后再应用。

## 先把戏写出来，格式可以一起看

自由文本和标准剧本显示的是同一份内容。你在一侧修改，另一侧同步更新；滚动和段落高亮也相互对应，少一次翻找，就少一次打断。

不熟悉剧本格式，可以从自由模式开始。习惯专业排版，就直接在标准剧本里写。两侧能单独关闭、左右互换，自由文本字号也能拖动调节。人物、动作、对白识别有歧义时，可以手动切换段落类型。

![自由文本与标准剧本同步显示，当前段落在两侧对应高亮](docs/public/images/split-writing.png)

## 一场戏一张便签，把整部故事放到眼前

还没想好正文，也能从白板开始。新增便签，写下场景标题和梗概，正文会同步出现标题，梗概留在白板上。

想调整结构，不必先剪切半天正文。白板便签、左侧场景列表和剧本共用场景顺序，拖动一张便签，那场戏就跟着移动。

双击可原位编辑场景标题和概括，标题同步回正文。概括可以自己写，也可以让模型整理，手写内容不会被自动覆盖。便签支持成组、评论、连线、改色和缩放；点击角落的跳转图标，就能回到那场戏继续写。

![场景白板用便签展示故事，排序与正文同步](docs/public/images/scene-board.png)

## 改这句对白，就把这句交给助理

编剧助理就在编辑页旁边。选中一段文字或一个场景，让它润色、优化对白或续写，先看改稿预览，再决定是否应用。也可以直接讨论人物和剧情，添加附件进行转写。

助理带有写作技能，你可以添加自己的技能，也能让模型起草一份，检查后安装。它能给建议，拍板的人还是你。

![编剧助理与正文并排，可选择写作技能和模型](docs/public/images/writing-assistant.png)

## 模型自己选，密钥不用反复填

支持配置多个自定义模型，保存后随时切换。可接入 OpenAI、兼容接口或本机 Ollama 服务；密钥保存在本机加密存储中，工程文件不携带密钥。

核心编辑无需模型。AI 功能使用你配置的服务，费用与额度由服务商决定，本软件不提供共享密钥。云模型会处理相关正文、记忆和技能内容；本机 Ollama 需另行安装并运行。

![保存多个自定义模型，并选择当前使用的模型](docs/public/images/custom-models.png)

模型配置不用猜。中文教程介绍国内的 DeepSeek 和硅基流动，写明官网入口、密钥获取、接口地址和连接测试。每个平台都有简短介绍，本机 Ollama 也有说明。

## 也能让你惯用的 Agent 来写

安装包内置 **CLI 和 MCP**。具备本机工具能力的 Codex、WorkBuddy、TRAE 等客户端，配置接入后可以读取场景、修改对白、调整结构。你可以留在熟悉的 Agent 里工作，幕后的修改落到剧本工程中。

软件里有接入说明。客户端需支持本机工具或 MCP，并完成连接配置；把配置贴进普通聊天框不会自动接通，也无需为了使用这些工具额外安装 Codex CLI。

## 换一台电脑，项目记忆也跟着走

配置可用模型后，项目记忆可自动整理设定、创作决定、建议和待确认的矛盾。作者锁定笔记由你掌握，最近 20 次自动记录可恢复。记忆随 `.screenplay` 工程保存，分享副本时也能选择不携带。

“个性化”记录你填写的写作偏好，保存在本机，对不同项目生效。自动整理可关闭，整理结果也需要你审阅。

## 写剧集，分集放在同一个工程里

一部剧不用拆成一堆文件。每集有自己的正文和白板，共用项目设定与记忆；可以新增、重命名、排序和切换，也能按集导出 PDF、Word、Markdown、FDX 等格式。只有一集时，可以取消分集，回到单篇剧本。

季纲总览把每集梗概、冲突、转折、结尾悬念和进度放在一起。先把故事走向理顺，再去写那些让人舍不得关掉的下一集。

配置模型后，可一次选择 2 至 8 集检查人物、时间线和伏笔疑点。报告带原文引用，点击回到对应内容，支持取消和标记处理状态。AI 只能帮你找疑点，结论仍需你核对，也不会直接改稿。

## 改名字不用求人，改稿不用凭记忆

张三要改成李四，在左侧人物列表点“重命名”。地点也一样。先看逐处预览，选择当前集或全部分集，再确认修改；搜索栏还有通用查找替换。这些功能不需要模型，确认后能整批撤销。匹配按字面进行，相近名称和上下文请自己把关。

版本历史支持命名稿号，按集对比修改前后的正文和规划，导出时携带稿号。第二稿改了什么，终于不用靠回忆。

## 日常写作需要的，也备着

- 场景标题在标准剧本中按项目设置统一格式，默认按“内外景、地点、时间”统一显示；支持美式和自定义模板。
- 标准剧本与中文阅读排版，按段落类型调整字体、字号、粗细、颜色和倾斜，保存命名样式。
- 自动保存、恢复、版本历史、最近项目，以及新工程保存位置选择。也能暂不保存试写。
- 搜索与场景、人物、地点、大纲导航。光标位置对应高亮，人物与地点可展开全部出现位置。
- 导入文本、Markdown、PDF 和图片，导出 PDF、Word、Markdown、Fountain、FDX、文本和 HTML。

PDF／图片转写需要配置模型并允许对应服务处理内容。识别和 AI 整理可能误判或遗漏，请对照原稿校对。自动保存也不能代替备份。

## 有新版，让软件提醒你

每天后台检查 GitHub，有新版时显示蓝色向上箭头。点击查看更新说明，下载后由你确认保存、重启安装。不会趁你写戏时突然重启。

“更多 → 检查更新”可以手动检查，“设置 → 软件更新”可以关闭自动检查。第一次仍需安装支持自动更新的版本，后续更新包会验证签名。详情见[更新说明](docs/UPDATES.md)。

## 三步开始

1. 下载 Release 中的 **DMG**，打开后拖入“应用程序”。源码 ZIP 不是安装包。
2. 新建或打开剧本，选标准剧本、自由模式或左右分栏，开始写。
3. 需要 AI 时，在“更多 → 设置 → 模型与技能”添加自己的模型；语言和个性化也在设置中。

核心编辑无需模型，也无需安装 Rust、Node.js 或 Codex CLI。外部 Agent 接入需要相应客户端支持本机工具或 MCP，并完成配置。

当前安装包为 Apple 芯片 Mac 测试版，未经过 Developer ID 正式签名和 Apple 公证；首次启动可能需要通过系统设置允许。不要关闭系统安全保护。Intel、Windows、Linux 尚未完成发行验收，本版本也不是 App Store 版本。

详细的数据处理方式见[隐私说明](docs/public/PRIVACY.md)。
