# 好好写剧本

**AI 时代的专业剧本工作台。**

灵感来了，先别跟缩进较劲。想改一场戏，也不必把半本剧本搬进聊天框。

好好写剧本把自由写作、剧本排版、场景白板和 AI 助理放在同一个项目里。格式有人管，修改有预览，故事还是你说了算。

## 写作，不必来回搬家

- **先自由写，再看专业排版。** 自由文本与标准剧本双向同步；分栏滚动与段落高亮也对应。可以只留一侧、左右互换，文字大小单独调。不熟悉格式也能先写，人物、动作、对白分类有歧义时再校正。
- **让你惯用的 Agent 操作剧本。** 安装包内置 CLI 和 MCP，具备本机工具能力的 Codex、WorkBuddy、TRAE 等客户端可配置接入，读取场景、修改对白、调整结构。贴一段配置进聊天框不会自动连接；软件里有接入说明。
- **编剧助理就在项目里。** 自选模型、多模型切换、写作技能、附件转写和局部改稿预览。选中段落或场景交给助理，检查结果后再应用；也能让模型起草技能，经你检查后安装。
- **故事铺开看，顺序一起改。** 白板便签、场景列表与正文顺序同步。拖动排序、成组、评论、连线、缩放；双击便签原位编辑标题与概括，标题同步到正文。概括能手写，也能由模型生成，手写内容不会被自动覆盖。
- **项目带着记忆走。** 配置可用模型后，项目记忆可自动整理设定、决定、建议和待确认矛盾。作者锁定笔记不由模型改写，最近20次自动记录可恢复；记忆随 `.screenplay` 保存，分享副本可选择不携带。个性化由你填写，留在本机，对所有项目生效。
- **少找位置，多写几行。** 光标对应的场景、地点、大纲会高亮；人物和地点可跳到最近出现处，也能展开全部位置。搜索、最近项目、导航折叠和助理侧栏布局，帮助你回到正在写的那一段。

这些单项功能并非全都独有。我们想做的是把它们接成一条顺手的工作流：**你写，软件排；你决定，AI 协助。**

## 格式和文件，都有自己的位置

支持标准剧本／中文阅读排版，按段落类型设置字体、字号、粗细、颜色和倾斜，保存命名样式。界面字号独立于纸面缩放。

工程使用 `.screenplay`，支持自动保存、恢复、版本历史，以及 PDF、Word、Fountain、FDX、文本和 HTML 导出。新工程先选择保存位置，或暂不保存试写；保存到文件后才有可管理的工程文件。自动保存不能代替备份。

文本、Markdown、PDF和图片等可导入。PDF／图片转写需要配置模型，并允许对应服务处理内容。识别与 AI 整理仍可能误判或遗漏，请对照原稿校对。

## 三步开始

1. 下载 Release 中的 **DMG**，打开后拖入“应用程序”。源码 ZIP 不是安装包。
2. 新建或打开剧本，选标准剧本、自由模式或左右分栏，开始写。
3. 需要 AI 时，在“更多 → 设置 → 模型与技能”添加自己的模型；语言和个性化也在设置中。

核心编辑无需模型，也无需安装 Rust、Node.js 或 Codex CLI。外部 Agent 接入需要相应客户端支持本机工具或 MCP，并完成配置。

当前安装包为 Apple 芯片 Mac 测试版，未经过 Developer ID 正式签名和 Apple 公证；首次启动可能需要通过系统设置允许。不要关闭系统安全保护。Intel、Windows、Linux 尚未完成发行验收，本版本也不是 App Store 版本。

## AI 的边界，说清楚

模型由你配置，费用与额度由服务商决定；软件不提供共享密钥或“无限免费”。使用云模型时，相关正文、记忆和技能内容会发送到你配置的服务。选择本机 Ollama 时，需要另行安装并运行模型服务。

自动记忆和改稿都需作者审阅；助理建议不等于已确认的创作决定。项目记忆跟文件走，个人偏好不跟文件走。具体见[隐私说明](docs/public/PRIVACY.md)。
